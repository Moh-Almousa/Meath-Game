# 🎮 لعبة الاختبارات الرياضية – C++

تطبيق تفاعلي يعمل من خلال سطر الأوامر (Console)، تم تطويره باستخدام لغة C++، ويجمع مجموعة من المفاهيم البرمجية وتقنيات حل المشكلات التي تدربت عليها خلال أول 50 مشكلة من دورة أبو هدهود.

يمثل هذا المشروع خطوة عملية للانتقال من حل المشكلات البرمجية بشكل منفصل إلى بناء تطبيق متكامل يجمع عدة مفاهيم برمجية ضمن بنية منظمة.

---

## 📌 نبذة عن المشروع

تتيح لعبة الاختبارات الرياضية للمستخدم إنشاء اختبار حسابي مخصص من خلال تحديد مجموعة من الخيارات:

* **عدد الأسئلة:** اختيار عدد الأسئلة من 1 إلى 10.
* **مستوى الصعوبة:** سهل، متوسط، صعب، أو مختلط.
* **نوع العملية الحسابية:** جمع، طرح، ضرب، قسمة، أو عمليات مختلطة.

بعد تحديد إعدادات الاختبار، يقوم البرنامج بتوليد أسئلة حسابية عشوائية وفقاً للإعدادات المختارة، ثم يستقبل إجابات المستخدم ويصححها تلقائياً، ويحسب عدد الإجابات الصحيحة والخاطئة، ويعرض النتيجة النهائية للاختبار.

كما يتيح البرنامج إعادة اللعب وإنشاء اختبار جديد دون الحاجة إلى إعادة تشغيل التطبيق.

---

## 🎯 مميزات التطبيق

* تحديد عدد الأسئلة قبل بدء الاختبار.
* اختيار مستوى صعوبة الأسئلة.
* توليد أرقام عشوائية وفقاً لمستوى الصعوبة.
* دعم العمليات الحسابية الأربع.
* إمكانية اختيار العمليات الحسابية بشكل مختلط.
* إمكانية اختيار مستوى الصعوبة بشكل مختلط.
* تصحيح الإجابات تلقائياً.
* تتبع عدد الإجابات الصحيحة والخاطئة.
* تحديد النتيجة النهائية (نجاح أو رسوب).
* عرض تقرير نهائي عن الاختبار.
* إمكانية إعادة اللعب.
* التحكم بشاشة سطر الأوامر وألوانها.

## 🧠 المفاهيم البرمجية المطبقة

يجمع هذا المشروع مجموعة من المفاهيم الأساسية في لغة C++ التي تمت دراستها والتدرب عليها خلال المشكلات البرمجية السابقة.

| المفهوم              | كيفية استخدامه في المشروع                          |
| -------------------- | -------------------------------------------------- |
| Enumerations (Enums) | تمثيل مستويات الأسئلة وأنواع العمليات الحسابية.    |
| Structures (Structs) | تنظيم بيانات السؤال والاختبار ضمن هياكل واضحة.     |
| Arrays               | تخزين مجموعة الأسئلة داخل الاختبار.                |
| Functions            | تقسيم البرنامج إلى دوال مستقلة ذات مسؤوليات محددة. |
| Function Parameters  | تمرير البيانات بين أجزاء التطبيق.                  |
| Pass by Reference    | تعديل بيانات الاختبار مباشرة من خلال الدوال.       |
| Switch Statements    | التعامل مع العمليات الحسابية ومستويات الصعوبة.     |
| If / Else            | التحقق من الإجابات وتحديد نتيجة الاختبار.          |
| Loops                | توليد الأسئلة والتحقق من الإدخال وإعادة اللعب.     |
| Random Numbers       | توليد الأرقام والعمليات الحسابية بشكل عشوائي.      |
| Type Casting         | تحويل القيم الرقمية إلى أنواع Enum.                |
| String Handling      | عرض رموز العمليات والرسائل النصية.                 |
| Conditional Logic    | تقييم أداء المستخدم وتحديد حالة النجاح أو الرسوب.  |
| Array Indexing       | الوصول إلى الأسئلة وإدارتها باستخدام الفهارس.      |

## 🏗️ آلية عمل التطبيق

يمر التطبيق بعدة مراحل مترابطة:

### 1. إعداد الاختبار

* تحديد عدد الأسئلة.
* اختيار مستوى الصعوبة.
* اختيار نوع العملية الحسابية.

### 2. توليد الأسئلة

* إنشاء أرقام عشوائية وفقاً لمستوى الصعوبة.
* تحديد العملية الحسابية.
* حساب الإجابة الصحيحة.
* تخزين بيانات كل سؤال داخل هيكل الاختبار.

### 3. تنفيذ الاختبار

* عرض الأسئلة واحداً تلو الآخر.
* استقبال إجابة المستخدم.
* مقارنة الإجابة المدخلة بالإجابة الصحيحة.

### 4. تصحيح الإجابات

* تسجيل الإجابات الصحيحة والخاطئة.
* تحديث نتيجة الاختبار بناءً على إجابات المستخدم.

### 5. عرض النتائج

* عرض عدد الأسئلة.
* عرض مستوى الصعوبة ونوع العمليات.
* عرض عدد الإجابات الصحيحة والخاطئة.
* تحديد النتيجة النهائية.

### 6. إعادة اللعب

* إتاحة الفرصة للمستخدم لبدء اختبار جديد.
